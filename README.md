# Character Counter

A simple character counter built using HTML, Tailwind CSS, and JavaScript.

### Features:
* Text area to type a message
* Real-time character counter
* Displays remaining characters
* Maximum limit of 200 characters
* Warning message when the character limit is reached

### Technologies Used:
* HTML
* Tailwind CSS (CDN)
* JavaScript

### How to Run: 
Open `index.html` in your browser and start typing a message.
This project helped me practice JavaScript event listeners and real-time input handling.
